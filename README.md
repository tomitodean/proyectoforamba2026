# proyectoforamba2026

Mi viaje a las raíces: el recorrido por el Friuli durante el proyecto FORAMBA 2026 (Civiform · Cividale del Friuli), contado como un árbol con las banderas de Argentina e Italia.

- Abrí `index.html` en el navegador para verlo.
- El botón ▶ (o la barra espaciadora) arranca el recorrido automático; las flechas ← → pasan de tarjeta.
- Agregando `#grabar` al final de la dirección se oculta el panel de botones y arranca solo (modo para grabar video).

Todo el sitio está en un solo archivo: las fotos y los videos van incluidos adentro.
